# Weatheria

**Know when to go out, not just how warm it is.**

[Weatheria](https://www.weatheria.com) is a free weather forecast site covering over 5 million places worldwide. Besides hourly and 7-day forecasts, it highlights the best two-hour window each day to be outside, and lets you compare up to three cities side by side.

- 🌍 11 languages, no sign-up needed
- ⏱️ Best outdoor window each day
- 🏙️ Compare up to three cities

Website: https://www.weatheria.com
